## Missed points

- A test can end with results other than plain pass/fail: it can be skipped, or end as an
  expected fail that counts as a pass (§Forcing a test to end with a given result; the note in
  §Passing and failing tests on `expect_fail` / `expect_error`).
- A test can be ended early as passed with `cocotb.pass_test`, and a `CancelledError` also ends
  it as passed (§Passing and failing tests).
- Assigned values are checked only against the signal's width, not its signedness; an
  out-of-range value raises an error (§Signed and unsigned values).
- When a test fails a stacktrace is printed, and with pytest installed it includes the values
  that made the assert fail (§Passing and failing tests).
- When a test ends, cocotb cancels all still-running tasks so they can clean up (§Cleaning up
  resources).
