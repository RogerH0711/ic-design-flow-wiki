# Review of S2 ingest

Reviewer: independent sub-agent, 2026-11-14
Statements checked: 125   Findings: 22

Scope: every sentence or list item under `wiki/` (excluding `wiki/log.md`) that
carries a `[S2 §...]` citation, as listed by `grep -rn "\[S2 §" wiki`. Only the
part attributed to S2 was checked, against
`raw/S02-librelane-newcomers-tutorial.md`. Citations to `§Newcomers' Tutorial`
were accepted for text that sits before the first sub-heading. The admonition
"More about IPVT corners" has no heading of its own and sits under `#### STA`,
so `§STA` was accepted for it.

The raw file contains no text that reads as instructions to a reviewer or agent
(its commands are tutorial steps for the human reader).

Findings marked "(minor)" are small additions or wording issues; the others
change or add meaning.

## Notes on statements accepted as OK

- `wiki/tools/verilator.md:18` and `wiki/tools/yosys.md:23` also rest on step
  directory names (`01-verilator-lint`, `06-yosys-synthesis`), but they restate
  the name literally and add no description of what the step does, so they were
  accepted. If the owner wants directory names treated as no evidence at all,
  these two fall with findings 3 and 4.
- `wiki/concepts/static-timing-analysis.md:25` ("…once more at signoff on the
  finished design, which gives the accurate result") was accepted: §STA says the
  mid-flow results "are not as accurate as `OpenROAD.STAPostPNR` since the
  design is not fully implemented yet". "The accurate result" is slightly
  stronger than "more accurate".
- `wiki/stages/routing.md:30` attributes diode insertion to the antenna repair
  step. §Antenna Check says LibreLane's approach is diode insertion and
  separately names `OpenROAD.RepairAntennas`; the link between the two is
  implied, not stated. Accepted.
