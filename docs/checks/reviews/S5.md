## Missed points

- Formal equivalence checking, besides simulation, has become an important
  way to validate RTL and lower-level representations (footnote [1], attached
  to §Levels of abstraction).
- HDL code is read by the synthesis tool, by one or more simulators, and
  sometimes by a formal verification tool, and verification depends on all of
  them interpreting the code the same way (§Standards compliance).
- "RTL synthesis" usually means more than replacing each RTL netlist element
  with an equivalent gate-level circuit: it also covers optimizations within
  the RTL representation, such as identifying memories and shareable
  resources (§Register-Transfer Level (RTL)).
- Gate-level netlists can be stored in several formats, for example EDIF, but
  an HDL netlist is often used because it is easy to simulate (§Logical gate
  level).
- Optimizations also differ in granularity (coarse-grained on complex cells
  such as adders and multipliers, fine-grained on single-bit gates) and in
  how well they scale to large designs (§Optimizations).
