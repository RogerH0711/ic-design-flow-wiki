## Missed points

- Build space libraries: SKY130 offers two; they are meant for use with
  things like memory compilers and to be built into larger macros, and they
  have their own design rules that allow higher density than other libraries
  (§Build Space Libraries). The wiki only lists "build space" as a type name.
- The File Types table gives, for each file type, an open and a closed
  tooling option with a status. Open tools (Magic, Netgen, Ngspice, Icarus
  Verilog) are mostly "Ready"; closed tools (Mentor Calibre, Cadence
  Virtuoso, Cadence Spectre) are "In progress" (§File Types). Only the Magic
  and Netgen entries reached the wiki; the open/closed comparison did not.
- The DRC and LVS decks exist in different formats per tool: a Magic techfile
  (plus a Netgen setup file for LVS) on the open side, SVRF rule decks for
  Mentor Calibre on the closed side (§File Types).
- A "GDS Generator" file type creates mask layout data, with Magic and a
  Magic techfile (§File Types). `magic.md` mentions it; no page on the PDK or
  on the kit's file list does.
- Who provides the libraries: the SkyWater foundry (`fd`), Efabless (`ef`)
  and Oklahoma State University (`osu`); names are lower case, joined by
  underscores, and the process field is always `sky130` (§Library Naming).
