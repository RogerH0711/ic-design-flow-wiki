# S4: LibreLane Glossary

## Summary

A glossary of about fifty short entries covering abbreviations, file formats, tools, and manufacturing terms used in the LibreLane documentation. [S4 §Glossary]

## Key points

- A process design kit is the set of files that models a fabrication process for the design tools. [S4 §PDK]
- A netlist represents pre-hardened elements, namely standard cells and macros, and the connections between them. [S4 §Netlist]
- GDSII is a binary format and the de facto industry standard for exchanging layout data. [S4 §GDSII]
- Tape-out is the final stage of IC design, when the design is sent to a fabrication facility. [S4 §tape-out]
- A design is said to have reached timing closure when timing analysis finds no violation at a given clock period at any timing corner. [S4 §timing closure]

## Coverage

- Definitions only, a few lines each. [S4 §Glossary]
